📚 Giới thiệu về dự án

Auction-Client là ứng dụng JavaFX cho hệ thống đấu giá trực tuyến. Nó giao tiếp với Auction-Server qua TCP socket, dùng JSON để trao đổi dữ liệu.

Ứng dụng được thiết kế theo SOLID principles và sử dụng nhiều Design Patterns để đảm bảo code dễ maintain, test, và mở rộng.

🎯 Các tính năng chính

✅ Validation: Input validation với rule chain
🔌 Networking: TCP socket communication
🎨 UI Utilities: FormHelper, Toast, Animations
🔐 Security: Password hashing (PBKDF2)
📊 Singleton Patterns: SceneNavigator
🏭 Factory Pattern: AuthValidatorFactory

📖 Cách sử dụng UML Documentation

1. Class Diagram: Bắt đầu tại đây để hiểu toàn bộ cấu trúc classes và mối quan hệ giữa chúng.

2. Data Flow & Sequence: Xem cách dữ liệu chảy qua hệ thống, đặc biệt flow login từ UI đến Server.

3. Patterns & Architecture: Hiểu các design patterns được sử dụng và kiến trúc 4 lớp của ứng dụng.
