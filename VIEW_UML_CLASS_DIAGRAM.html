Auction-Shared - Shared module (DTOs, Models, Validators)
Auction-Client - Client module (Controllers, UI)
Controllers - FXML controllers, handle user interaction
Validators - Implement Validator interface
UI Utilities - Helper classes for UI operations
Network - Socket communication layer

🔗 Mối quan hệ chính

• LoginController → LoginValidator (validate user input)
• LoginValidator → ValidationResult (collect errors)
• LoginController → SocketClient (send to server)
• FormHelper → ValidationResult (display errors on UI)
• SceneNavigator (Singleton) → manages stage scenes
• AuthValidatorFactory → creates validators (Factory pattern)
