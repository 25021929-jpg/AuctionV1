🔗 Component Interaction - Chi tiết từng bước

Login Flow - Chi tiết

Bước 1 (UI): User nhập email/username + password, nhấn Login button → kích hoạt handleLogin()

Bước 2 (Controller): LoginController tạo LoginRequest object từ inputField values

Bước 3 (Validation): Gọi LoginValidator.validate(request) với rules chain: NotBlankRule → EmailOrUsernameRule → PasswordRule

Bước 4 (Error handling): Nếu có lỗi, FormHelper.applyErrors() highlight fields. Nếu hợp lệ, tiếp tục

Bước 5 (Network): Cấu tạo Request object: { action: "AUTH_LOGIN", body: JSON(LoginRequest) }

Bước 6 (Socket): SocketClient.sendRequest() gửi JSON qua TCP tới server port 8888

Bước 7 (Server): Server nhận, parse, dispatch tới AuthController, xác minh credentials

Bước 8 (Response): Server tạo Response<AuthResponse> với success=true/false, trả lại client

Bước 9 (UI Update): Client parse response, nếu success navigate to MainView, else hiển thị error toast
